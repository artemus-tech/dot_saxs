## Что сделано

- **Решение** `DotSaxs.slnx` (.NET 10, C# 14): сборки `Std`, `Np`, `SciPy`, `Extensions`, `Sparse`, `Data`; тесты
  `Conventions.Tests`, `Testing.Tests`, `Data.Tests` и библиотека для тестов `Testing`. Предупреждения — ошибки,
  XML-документация в `src` обязательна; версии закреплены: SDK, пакеты, numpy и scipy, образы по digest, действия по SHA.
- **Тесты соглашений**: `[Original]` у каждого публичного члена порта, строка оригинала на закреплённом коммите
  содержит имя, порт без внешних зависимостей, `names.csv` сходится с портом.
- **Схема API** (DECISIONS.md п. 22–26): `Vector`, `Matrix`, `CubeMatrix`, `Tensor4D` … `Tensor8D`, `SparseMatrix`; без
  `axis`, broadcasting и операторов у массивов; сборки по темам; план этапов п. 25 утверждён.
- **names.csv** — справочник переноса: у каждого публичного имени numpy 2.5.4 и scipy 1.18.1 — имя в C#, как это
  делается у нас, пример вызова и этап плана. Ждёт утверждения.
- **Эталоны** (`tools/reference`, `tests/references`): генератор в эталонном контейнере сам ставит параметры процессора
  (п. 4); первые кейсы — `numpy.add`, `numpy.sum` (побитово), `numpy.exp` (ULP), `numpy.linalg.solve` (допуск), с ошибками
  и предупреждениями Python.
- **Чтение .npy для тестов** (`DotSaxs.Testing`): заголовки 1.0–3.0, 14 видов чисел, оба порядка байт, порядок
  Fortran; уровни совпадения и сравнение массивов с понятным текстом расхождения.
- **База** (`DotSaxs.Data`, PostgreSQL 17, EF Core 10): эталоны (массивы — ссылка на файл и SHA-256), история прогонов,
  кэш результатов, очередь задач через `FOR UPDATE SKIP LOCKED`; первая миграция; интеграционные тесты в CI.

## Найдено и исправлено по ходу

1. Столбец «этап» в `names.csv` расходился с утверждённым планом: `numpy.pad` и `numpy.loadtxt` стояли на этапе 5, хотя
   работа с формой и чтение файлов — этап 2; `numpy.matmul` — на 2, хотя `LinAlgMultiply` — этап 3. Этап теперь по плану,
   тест сверяет примеры. У дискретных распределений пример вызова — `Pmf`, а не `Pdf`.
2. Артефакты GitHub из облачной среды не скачать: хранилище закрыто прокси. CI печатает новые эталоны и миграции в лог
   (tar.gz в base64), оттуда они и берутся.
3. `dotnet ef` без восстановления пакетов не находил `project.assets.json` — в задание `migrations` добавлен `restore`.
